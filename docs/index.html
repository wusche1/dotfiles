herdr + Claude Code

A take-home guide for running terminal coding sessions

herdr keeps your work alive in the background. Close the terminal, sleep the laptop, or drop an SSH connection — your workspaces (and Claude) keep running. You just run herdr again. Almost every command is the prefix Ctrl+Space (press and release), then a key. Ctrl+Space ? shows them all.

PREFIXCtrl+Space

The mental model

herdr nests three layers. Give each one a job and you always know where things live.

Workspace = project. One per repo, listed in the sidebar. A workspace stays alive when you detach and walk away.

Tab = branch. Inside a project, one tab per branch / git worktree. Claude can refactor on one branch while another sits untouched in the next tab.

Pane = agent vs. your eyes. Split a tab so the agent works in one pane while you watch the code, run tests, or read a diff in the other.

In one line: workspace = which project, tab = which branch, pane = agent vs. your view of the code. The sidebar also shows which agents are working, idle, or waiting for you.

Survival keys

If you remember nothing else, remember these.

Ctrl+SpacethenqDetach — leave everything running and walk away
herdrReattach to everything that is running
Ctrl+Spacethen?Show every keybinding
Ctrl+Spacethen[Scroll up to read history — vim keys to move, q to quit

Tabs = branches

One per branch / worktree. Tabs are listed under their workspace in the sidebar.

Ctrl+SpacethenShift+WCreate a git worktree + tab for a new branch in one step
Ctrl+SpacethencNew tab (same branch)
Ctrl+Spacethenn / pNext / previous tab
Ctrl+Spacethen1 2 3Jump to tab by number
Ctrl+SpacethenShift+TRename the current tab
Ctrl+SpacethenAlt+XClose the current tab

Panes = code + agents

Split the screen so the agent and your view of the code sit side by side.

Ctrl+SpacethenvSplit left/right (e.g. Claude left, terminal right)
Ctrl+SpacethensSplit top/bottom
Ctrl+h j k lMove between panes (vim directions, no prefix needed)
Ctrl+SpacethenzZoom the current pane to full size (again to undo)
exitClose a pane

Workspaces = projects

One per repo. Switching projects means switching workspaces, not closing them.

Ctrl+SpacethenShift+SNew workspace, starting in ~/Projects — then cd into your repo
Ctrl+SpacethenwWorkspace picker — j/k to move, Enter to open
Ctrl+SpacethenShift+1 2 3Jump to workspace by number
Ctrl+SpacethenShift+ERename the current workspace
Ctrl+SpacethenShift+XClose a workspace (closes all its tabs)

Agents

herdr tracks every Claude session. The sidebar icon tells you who needs you.

Ctrl+SpacethenaJump to the next agent, across all workspaces
Ctrl+SpacethenShift+APrevious agent
Ctrl+SpacethenCtrl+1 2 3Jump to agent by number
Ctrl+SpacethenoOpen the pane behind the latest notification

Copy & paste

Mouse selection copies directly — this is the keyboard way.

Ctrl+Spacethen[Enter scroll/copy mode
vStart selecting (then move with vim keys)
yCopy selection and exit
Cmd+VPaste (normal terminal paste)

A typical Claude Code session

1. herdr — opens your workspaces, or starts fresh

2. Ctrl+Space Shift+S → new workspace, cd into your project

3. Run claude

4. Need a scratch terminal? Ctrl+Space v

5. New task / branch? Ctrl+Space Shift+W spins up a worktree + tab

6. Walking away? Ctrl+Space q — Claude keeps working

7. Back later? herdr, then Ctrl+Space a jumps to the next agent
